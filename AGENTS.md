# Rules for coding agents in bambuhelper-smart-display

These hold for every agent (Claude Code, Codex, others). Read `CONTRIBUTING.md` first: it holds this repository's
rules (one firmware candidate PR at a time, the deterministic source inputs, what never to commit).

- **Read the Home Platform design contract before any UI work**: appliance-ui `DESIGN.md`
  (https://github.com/azmusgb/appliance-ui/blob/main/DESIGN.md), and its section "The workshop display (480 × 320,
  touch)" in particular. Read it at the start of the task, not from memory or from this summary. Pi Hub's platform
  baseline and its approved amendments win where they differ. If you can't open it (no network, no access), say so and
  stop before changing a screen.
- Colours, type and components come from the kit; a new one is proposed in appliance-ui first, never added here alone.
