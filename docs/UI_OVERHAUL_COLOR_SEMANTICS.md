# v11.25 color semantics

The physical UI uses color as meaning, not decoration.

| Token | Meaning |
| --- | --- |
| neutral panel/background | default structure and information |
| cyan/blue | ordinary interaction, selected navigation, informational focus |
| green | ready/success/healthy only |
| amber/orange | caution, staged, attention, guarded non-destructive commit |
| red | destructive action, error, unsafe/offline critical state |
| muted/dim | unavailable, secondary, unknown/unreported context |

A page must not assign a different accent to every card merely to differentiate categories. Hierarchy should come from placement, spacing, typography and labels first.
