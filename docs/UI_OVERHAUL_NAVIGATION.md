# v11.25 navigation contract

Persistent primary destinations are `Home`, `Printer`, `Workshop`, and `More`.

Printer owns its local `STATUS`, `AMS`, and `CONTROL` modes. Those modes do not become additional global destinations.

System/Display/Tools/Custom are launched from More. Network and rotation remain staged specialist flows beneath those entry points.

The Back action returns one level. It must not depend on tapping an unlabeled page region or holding a generic surface.
