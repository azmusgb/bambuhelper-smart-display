# v11.25 attention hierarchy

Attention is a cross-screen concept, not a new authority.

Home may surface only evidence-backed device/workshop conditions already known to Workshop OS, such as offline printer, paused print, timer completion, device health issue or an explicitly configured power/network warning.

Inventory-derived attention must come from the versioned Filament Inventory device contract and remains Unknown/unavailable when that contract does not provide it.

Do not generate an attention badge merely because a screen has stale render state or because color/material appears unusual.
